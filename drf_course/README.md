# Курс по Django REST Framework: превращаем блог в API

Этот курс создан для тех, кто уже прошёл базовый курс по Django и хочет
научиться строить REST API с помощью Django REST Framework (DRF).

## Как устроен курс

Курс построен по принципу **«берём готовый блог и превращаем его в API»**.
Мы шаг за шагом добавим REST API к проекту, созданному в курсе по Django:
посты, комментарии, пользователи — всё станет доступно через HTTP-запросы.

Каждый урок состоит из двух частей:

- **`teoria.md`** — краткая теория с простыми объяснениями терминов.
- **`primery/`** — практические Python-скрипты и фрагменты кода, которые
  можно запускать и смотреть, как они работают.

## Что означает слово «скрипт» в названии курса

`Скрипт` — это просто файл с кодом на Python (или другом языке), который
выполняет какую-то задачу. В веб-разработке ещё есть «терминал» /
«командная строка» — окно, куда вводят команды вроде `python manage.py`.
Команды в курсе помечаются знаком `>` в начале строки.

## Для кого этот курс

Ты должен уже:
- знать Python на базовом уровне;
- понимать, что такое Django, модели, views, URL (пройден курс по Django);
- иметь рабочий проект-блог с моделями Post и Comment.

## Темы курса

| № | Тема | Что изучаем |
|---|------|-------------|
| 1 | Введение в DRF и REST | Что такое API, REST, JSON, установка DRF |
| 2 | Сериализаторы | Превращение моделей в JSON, ModelSerializer |
| 3 | Function-Based Views + @api_view | Простые API-эндпоинты на функциях |
| 4 | Class-Based Views: APIView | ООП-подход к API |
| 5 | Generic Views: быстрый CRUD | ListCreateAPIView и другие дженерики |
| 6 | ViewSets и Routers | Один класс — все эндпоинты, авто-URL |
| 7 | Аутентификация и permissions | TokenAuth, IsAuthenticated, права доступа |
| 8 | Пагинация, фильтрация, поиск | PageNumberPagination, SearchFilter |
| 9 | Вложенные сериализаторы и связи | Nested Serializer для Comment внутри Post |
| 10 | Документация и продвинутые техники | Swagger, throttling, кастомные actions |

## Как проходить курс

1. Иди строго по порядку — каждый следующий урок опирается на предыдущий.
2. Сначала читай `teoria.md`, потом выполняй код из папки `primery/`.
3. Не копируй бездумно: набирай код руками, экспериментируй, ломай и чини.
4. Если команда не сработала — прочитай текст ошибки, это часть обучения.

## Что нужно установить заранее

- **Python** (версия 3.10 или новее) — уже установлен из курса по Django.
- **Django** — уже установлен из курса по Django.
- **Проект-блог** — результат прохождения курса по Django (модели Post и
  Comment в приложении `blog`).

Установку DRF разберём в первом уроке.

## Итог курса

После прохождения всех уроков у тебя будет:

- полноценное REST API для блога (посты, комментарии, пользователи);
- понимание, как DRF устроен «изнутри» (сериализаторы, views, роутеры);
- Swagger-документация для твоего API;
- умение строить API для любого Django-проекта.

Удачи в изучении!
