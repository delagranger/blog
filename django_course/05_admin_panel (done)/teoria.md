# Урок 5. Админ-панель

## Что такое админ-панель?

**Админ-панель (admin)** — это готовый интерфейс управления сайтом, который
Django даёт бесплатно. Через неё ты (или владелец сайта) можешь добавлять,
изменять и удалять записи в базе данных — прямо через браузер, без написания
кода.

Это одна из главных «фишек» Django. В других фреймворках такую панель часто
приходится писать с нуля, а здесь она уже готова.

## Создаём суперпользователя

Чтобы зайти в админку, нужен аккаунт с правами администратора. Создадим его:

```
> python manage.py createsuperuser
```

Django попросит ввести:

- имя пользователя (username);
- электронную почту (можно оставить пустой, нажав Enter);
- пароль (при вводе символы не отображаются — это нормально, защита).

После этого запусти сервер и открой:

```
http://127.0.0.1:8000/admin/
```

Войди с логином и паролем, которые только что создал, — ты попадёшь в
админ-панель.

## Регистрируем модель в админке

Пока в админке пусто — Django не знает, что показывать. Нужно зарегистрировать
нашу модель `Post`. Открой `blog/admin.py`:

```python
from django.contrib import admin
from .models import Post

admin.site.register(Post)
```

Разберём:

- `from .models import Post` — берём модель из соседнего файла (точка —
  «текущая папка blog»).
- `admin.site.register(Post)` — «покажи модель Post в админ-панели».

Обнови страницу админки — появится раздел `BLOG` с нашей моделью `Post`.
Теперь ты можешь добавлять посты через браузер: нажми «Add» (Добавить),
заполни заголовок и текст, сохрани.

## Что означает «строка объекта»

Если ты уже регистрировал модель, то мог заметить: записи отображаются как
`Post object (1)`, `Post object (2)` — некрасиво и непонятно.

Чтобы Django показывал нормальное название, добавь модели метод `__str__`:

```python
class Post(models.Model):
    zagolovok = models.CharField(max_length=200)
    tekst = models.TextField()

    def __str__(self):
        return self.zagolovok
```

`__str__` — «магический метод» Python, который задаёт, как объект выглядит
в виде строки. Теперь в админке записи будут отображаться по заголовку.

## Настраиваем внешний вид списка

Простая регистрация показывает только одну колонку. Сделаем таблицу
удобнее с помощью класса-настройки:

```python
from django.contrib import admin
from .models import Post


class PostAdmin(admin.ModelAdmin):
    list_display = ("zagolovok", "data_sozdaniya")  # колонки в таблице
    list_filter = ("data_sozdaniya",)               # фильтр справа
    search_fields = ("zagolovok",)                  # строка поиска


admin.site.register(Post, PostAdmin)
```

Разберём атрибуты:

- `list_display` — какие поля показывать колонками.
- `list_filter` — добавляет боковую панель для фильтрации записей.
- `search_fields` — по каким полям искать через поисковую строку.

> Внимание: у атрибутов `list_filter` и `search_fields` в конце обязательна
> запятая внутри скобок, потому что это кортежи (tuply) из одного элемента.

## Зачем нужна админка?

- Быстро проверить данные во время разработки.
- Наполнить сайт контентом без написания кода.
- Дать заказчику простой интерфейс управления сайтом.

## Словарик терминов

- **Суперпользователь (superuser)** — администратор с полными правами.
- **Зарегистрировать модель** — сказать Django «показывай эту модель в админке».
- **Кортеж (tuple)** — неизменяемый список в Python, записывается в скобках.
