# Урок 6. Templates (шаблоны)

## Зачем нужны шаблоны?

До сих пор наши View возвращали простой текст через `HttpResponse`.
Но настоящий сайт состоит из HTML — языка разметки веб-страниц.

**Шаблон (template)** — это файл, в котором HTML-разметка смешана с
особыми «вставками» языка шаблонов Django (DTL — Django Template Language).
View готовит данные, а шаблон красиво их показывает.

Вспомним схему MVT: View передаёт данные в Template, а Template превращает
их в готовую HTML-страницу для пользователя.

## Создаём папку для шаблонов

Django ищет шаблоны в папках, указанных в настройках. Сделаем общепринятую
структуру:

```
blog/
└── templates/
    └── blog/
        └── glavnaya.html
```

Заметка: внутри `templates/` мы создаём вложенную папку `blog/`. Это защита
от путаницы, когда в проекте несколько приложений с шаблонами с одинаковыми
именами.

## Первый шаблон

Создай файл `blog/templates/blog/glavnaya.html`:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Мой блог</title>
</head>
<body>
    <h1>Добро пожаловать в мой блог!</h1>
</body>
</html>
```

## Возвращаем шаблон из View

Изменим `glavnaya` в `blog/views.py`:

```python
from django.shortcuts import render
from .models import Post


def glavnaya(request):
    posts = Post.objects.all()
    return render(request, "blog/glavnaya.html", {"posts": posts})
```

Разберём новый элемент — функцию `render`:

- `request` — запрос (тот же, что пришёл в View).
- `"blog/glavnaya.html"` — путь к шаблону.
- `{"posts": posts}` — **контекст**: словарь, через который данные
  попадают в шаблон.

Контекст — это «посылка», которую View отправляет шаблону. Ключ — имя,
по которому шаблон обратится к данным.

## Как шаблон использует данные (DTL)

Язык шаблонов Django использует три главных конструкции:

- `{{ переменная }}` — вывести значение.
- `{% тег %}` — логика (циклы, условия, наследование).
- `{{ переменная|фильтр }}` — изменить значение при выводе.

### Вывод значения

```html
<h1>{{ post.zagolovok }}</h1>
```

Точка означает доступ к атрибуту: `post.zagolovok` — «у объекта post возьми
поле zagolovok».

### Цикл

```html
{% for post in posts %}
    <h2>{{ post.zagolovok }}</h2>
    <p>{{ post.tekst }}</p>
{% empty %}
    <p>Постов пока нет.</p>
{% endfor %}
```

- `{% for post in posts %}` — перебрать список из контекста.
- `{% empty %}` — что показать, если список пуст.
- `{% endfor %}` — конец цикла (в DTL все блоки явно закрываются).

### Условие

```html
{% if posts %}
    <p>Есть посты!</p>
{% else %}
    <p>Постов нет.</p>
{% endif %}
```

## Наследование шаблонов

У всех страниц сайта обычно одинаковый «каркас»: шапка, меню, подвал.
Чтобы не копировать его в каждом файле, Django использует наследование.

Создай базовый шаблон `blog/templates/blog/osnova.html`:

```html
<!DOCTYPE html>
<html>
<head>
    <title>{% block zagolovok %}Мой блог{% endblock %}</title>
</head>
<body>
    <header>Шапка сайта</header>

    <main>
        {% block soderzhimoye %}{% endblock %}
    </main>

    <footer>Подвал сайта</footer>
</body>
</html>
```

- `{% block imya %}` — «место», которое дочерние шаблоны могут заполнить
  своим содержимым. По-английски block = «блок».

Теперь перепишем `glavnaya.html`, унаследовав каркас:

```html
{% extends "blog/osnova.html" %}

{% block zagolovok %}Главная{% endblock %}

{% block soderzhimoye %}
    <h1>Добро пожаловать!</h1>
    {% for post in posts %}
        <h2>{{ post.zagolovok }}</h2>
    {% endfor %}
{% endblock %}
```

- `{% extends "blog/osnova.html" %}` — «я наследую от базового шаблона».
- Дальше заполняем только нужные блоки.

Теперь для новой страницы достаточно создать короткий шаблон, унаследовав
готовый каркас.

## Полезные фильтры

Фильтры меняют значение при выводе:

```html
{{ post.zagolovok|lower }}          <!-- все буквы строчные -->
{{ post.tekst|truncatewords:10 }}   <!-- первые 10 слов -->
{{ post.data_sozdaniya|date:"d.m.Y" }}  <!-- дата в формате 22.08.2026 -->
```

## Ссылки в шаблонах: тег url

Вместо «зашитых» адресов используй тег `{% url %}`:

```html
<a href="{% url 'post' post.id %}">Читать</a>
```

где `'post'` — имя маршрута из `urls.py` (о `name` подробнее в следующем
примере). Это надёжнее: если адрес изменится, ссылки пересчитаются сами.

## Словарик терминов

- **HTML** — язык разметки, из которого состоят веб-страницы.
- **Контекст** — данные, которые View передаёт в шаблон.
- **DTL** — язык шаблонов Django.
- **Наследование** — использование общего каркаса в нескольких шаблонах.
