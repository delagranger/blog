# Урок 11. QuerySet API

## Что такое QuerySet?

В уроке 4 мы познакомились с ORM и запросом `Post.objects.all()`.
Результат такого запроса — **QuerySet**.

**QuerySet** — это набор объектов из базы данных, с которым можно
работать дальше: фильтровать, сортировать, исключать, нарезать.
Главная особенность — QuerySet **ленивый**: запрос к базе выполняется
только тогда, когда данные реально нужны (например, при выводе в шаблоне).

Подробно работать с QuerySet помогает так называемый **QuerySet API** —
встроенные методы, которые «складываются» в цепочки.

## Основные методы

Наша модель — `Post` (пост блога). Разберём самые нужные методы.

### all() — все записи

```python
Post.objects.all()
```

### filter() — отобрать по условию

```python
Post.objects.filter(published=True)
Post.objects.filter(zagolovok__contains="Django")
```

Двойное подчёркивание `__` — особый синтаксис «просмотра внутрь» поля
(lookup). `contains` означает «содержит подстроку» (учёт регистра).
Есть и нечувствительный к регистру вариант `icontains`.

### exclude() — исключить по условию

```python
Post.objects.exclude(published=False)
```

### get() — ровно одна запись

```python
post = Post.objects.get(pk=1)
```

Вернёт один объект. Если записей нет — ошибка `DoesNotExist`,
если больше одной — `MultipleObjectsReturned`.

### order_by() — сортировка

```python
Post.objects.order_by("data_sozdaniya")        # по возрастанию
Post.objects.order_by("-data_sozdaniya")       # по убыванию (минус)
```

## Сравнение и диапазоны

```python
Post.objects.filter(cena__lt=100)    # меньше (<)
Post.objects.filter(cena__lte=100)   # меньше или равно (<=)
Post.objects.filter(cena__gt=50)     # больше (>)
Post.objects.filter(cena__gte=50)    # больше или равно (>=)
```

## Цепочки методов

Методы можно объединять в цепочку — каждый следующий уточняет результат:

```python
Post.objects.filter(published=True).order_by("-data_sozdaniya")
```

Читается слева направо: «возьми посты, где published=True, отсортируй
по дате по убыванию».

## Методы-агрегаты

Вернуть не список, а одно число:

```python
Post.objects.count()      # сколько всего записей
Post.objects.first()      # первая запись (или None)
Post.objects.last()       # последняя запись (или None)
```

## Проверка существования

```python
Post.objects.filter(zagolovok="Django").exists()
```

Вернёт `True` или `False`. Работает быстрее, чем `count()` в этом случае.

## Срез (как у списков)

```python
Post.objects.all()[:5]     # первые 5 записей
```

Часто используется для «последних новостей».

## Каскад методов для поиска по связям

Если у поста есть внешний ключ на автора (`author`), можно фильтровать
по полю связанной модели:

```python
Post.objects.filter(author__username="anna")
```

`author__username` — «у автора поста взять поле username».

## Ленивый QuerySet

QuerySet не выполняет запрос сразу. Посмотри:

```python
qs = Post.objects.filter(published=True)  # запрос ещё НЕ выполнен
```

Как только данные понадобятся (цикл, вывод в шаблоне, `len()`), Django
отправит запрос в базу. Это экономит ресурсы, когда цепочка методов
собирается по частям.

## Словарик терминов

- **Lookup** — условие через `__` (например, `icontains`, `lte`).
- **Ленивый** — выполняется не сразу, а когда данные нужны.
