# Урок 4. Models и база данных

## Что такое база данных?

**База данных (БД)** — это место, где сайт хранит свою информацию: посты,
пользователей, комментарии, заказы. Без БД сайт «забывал бы» всё после
каждого перезапуска.

Django по умолчанию работает с **SQLite** — это база данных, которая хранится
в одном обычном файле (`db.sqlite3`). Для обучения она идеальна: ничего
настраивать не нужно.

## Что такое ORM?

Обычно, чтобы работать с базой данных, нужно писать команды на особом языке
**SQL** (например, `SELECT * FROM blog_post;`). Это неудобно и легко
ошибиться.

**ORM (Object-Relational Mapping)** — «переводчик», который позволяет
работать с базой через обычный Python-код, без SQL. Вместо строк запроса
ты используешь классы и их методы.

```
Ты пишешь (Python):        Post.objects.all()
Django внутренне делает:   SELECT * FROM blog_post;
```

То есть ORM — это прослойка между твоим Python-кодом и базой данных.

## Что такое модель?

**Модель (Model)** — это класс Python, который описывает таблицу в базе
данных. Каждый атрибут класса — это колонка таблицы.

Пример — модель поста для блога:

```python
from django.db import models


class Post(models.Model):
    zagolovok = models.CharField(max_length=200)
    tekst = models.TextField()
    data_sozdaniya = models.DateTimeField(auto_now_add=True)
```

Разберём построчно:

- `class Post(models.Model)` — объявляем модель, наследуюясь от встроенного
  `models.Model`. Наследование — это «взять всё готовое и добавить своё».
- `zagolovok = models.CharField(max_length=200)` — текстовое поле до 200
  символов (заголовок).
- `tekst = models.TextField()` — большое текстовое поле.
- `data_sozdaniya = models.DateTimeField(auto_now_add=True)` — дата и время,
  заполняется автоматически при создании записи.

Эта модель создаст в базе таблицу с колонками `zagolovok`, `tekst` и
`data_sozdaniya`.

## Часто используемые типы полей

- `CharField(max_length=N)` — короткая строка (имя, заголовок).
- `TextField()` — длинный текст (статья, описание).
- `IntegerField()` — целое число.
- `BooleanField()` — да/нет (True/False).
- `DateTimeField()` — дата и время.
- `EmailField()` — поле для e-mail (Django проверяет формат).
- `ImageField()` — картинка (разберём в уроке 9).
- `ForeignKey()` — связь «один ко многим».
- `ManyToManyField()` — связь «многие ко многим».

## Миграции: как модель попадает в базу

Написал модель — но база данных о ней ещё не знает. Нужно сделать два шага.

### Шаг 1. Создать файл миграции

```
> python manage.py makemigrations blog
```

**Миграция** — это файл-инструкция: «создай такую-то таблицу с такими-то
колонками». Эта команда смотрит на твои модели и генерирует такую инструкцию.

### Шаг 2. Применить миграцию к базе

```
> python manage.py migrate
```

Эта команда выполняет все невыполненные миграции — реально меняет базу данных.

Запомни порядок: **сначала makemigrations, потом migrate**.

> Подсказка: `makemigrations` — «приготовь изменения», `migrate` — «примени их».

## Связи между моделями

В реальном блоге у поста есть автор (пользователь), а у поста — комментарии.
Это связи «один ко многим».

```python
class Comment(models.Model):
    post = models.ForeignKey(Post, on_delete=models.CASCADE)
    text = models.TextField()
```

- `ForeignKey` — «один пост имеет много комментариев».
- `on_delete=models.CASCADE` — «если пост удалили, удали и его комментарии».

## Как работать с данными (первые команды ORM)

Интерактивная консоль Django — отличное место для экспериментов:

```
> python manage.py shell
```

Внутри неё попробуй:

```python
from blog.models import Post

# Создать запись
Post.objects.create(zagolovok="Первый пост", tekst="Привет, мир!")

# Достать все записи
Post.objects.all()

# Найти одну запись
Post.objects.get(zagolovok="Первый пост")
```

Здесь `objects` — это «менеджер» модели, твой помощник для запросов к базе.

## Вспоминаем ORM-команды

| Команда ORM | Что делает |
|-------------|-----------|
| `Model.objects.all()` | все записи |
| `Model.objects.create(...)` | создать запись |
| `Model.objects.get(...)` | найти одну (ошибка, если нет) |
| `Model.objects.filter(...)` | найти несколько по условию |

Подробно о запросах поговорим в уроке 11 (QuerySet API).

## Словарик терминов

- **Таблица** — хранение данных в виде строк и колонок.
- **Поле** — одна колонка таблицы.
- **Запись** — одна строка таблицы (например, один пост).
- **Миграция** — сохранённое изменение структуры базы данных.
