# Курс по Django: с нуля до базово-среднего уровня

Этот курс создан для начинающих программистов, которые хотят изучить Django.
Все термины объясняются простым языком, без жаргона.

## Как устроен курс

Курс построен по принципу **«один реальный проект, который растёт»**.
Мы будем шаг за шагом создавать проект-блог: от пустой папки до сайта
с постами, пользователями, формами и админ-панелью.

Каждый урок состоит из двух частей:

- **`teoria.md`** — краткая теория с простыми объяснениями терминов.
- **`primery/`** — практические Python-скрипты и фрагменты кода, которые
  можно запускать и смотреть, как они работают.

## Что означает слово «скрипт» в названии курса

`Скрипт` — это просто файл с кодом на Python (или другом языке), который
выполняет какую-то задачу. В веб-разработке ещё есть «терминал» /
«командная строка» — окно, куда вводят команды вроде `python manage.py`.
Команды в курсе помечаются знаком `>` в начале строки.

## Темы курса

| № | Тема | Что изучаем |

| 1 | Введение и установка | Что такое Django, MVT, установка, виртуальное окружение |

| 4 | Models и база данных | ORM, поля, связи, миграции |
| 5 | Админ-панель | Регистрация моделей, настройка отображения |

## Как проходить курс

1. Иди строго по порядку — каждый следующий урок опирается на предыдущий.
2. Сначала читай `teoria.md`, потом выполняй код из папки `primery/`.
3. Не копируй бездумно: набирай код руками, экспериментируй, ломай и чини.
4. Если команда не сработала — прочитай текст ошибки, это часть обучения.

## Что нужно установить заранее

- **Python** (версия 3.10 или новее) — язык программирования, на котором
  написан Django.
- **Текстовый редактор** (например, Visual Studio Code) — программа для
  написания кода.
- **Терминал / командная строка** — окно для ввода команд.

Установку всего этого разберём в первом уроке.

## Итог курса

После прохождения всех уроков у тебя будет:

- рабочий проект-блог с постами и пользователями;
- понимание, как устроен Django «изнутри»;
- умение читать документацию Django и разбираться в чужом коде.

Удачи в изучении!
